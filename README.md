Motor de Processamento Cashless

Script em Python demonstrando a integração entre Orientação a Objetos, Lógica Transacional e SQL.

Funcionalidades:

Simulação de banco de dados relacional com sqlite3 (em memória).

Encapsulamento de regras de negócio em Classes (POO).

Processamento em lote de fila de transações através de laços de repetição.

Ciclo CRUD aplicado na prática (Injeção de estado inicial, leitura, validação e persistência do estado final).

Como rodar: Basta executar python motor_cashless.py no terminal.
